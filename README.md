# ArtikAi Website

Marketing site and app shell built with Vite + React + TypeScript.

## Commands

- `pnpm dev` — run the dev server
- `pnpm build` — production build
- `pnpm preview` — preview the production build locally
- `pnpm lint` — lint the codebase

## Notes

- Environment variables: none are required for local development beyond Vite defaults.
- Service worker and icons live in `public/`; adjust with care if updating assets.
